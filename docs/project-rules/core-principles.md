# 핵심 원칙

- MVP는 국내 가상 호텔 속초·설악산·제주도 3개 지점, 지점당 객실 유형 3~4개다. 속초와 설악산은 별도 지점으로 관리한다.
- 고객 흐름: 호텔 탐색 → 직접 검색 또는 AI 상담 → 테스트 결제 → 예약 조회·취소.
- 직원 흐름: 예약 확인 → 객실 배정 → 체크인 → 체크아웃 → 청소 완료.
- 숙박 재고는 지점 현지 날짜의 체크인일 이상, 체크아웃일 미만에 적용한다. 첫 지점들은 Asia/Seoul을 사용한다.
- 여러 숙박일의 재고 확보는 전부 성공하거나 전부 취소한다. 재고는 음수가 될 수 없다.
- 임시 확보 만료, 결제 성공, 취소의 경합과 중복 요청을 DB 트랜잭션으로 처리한다.
- 예약 당시 일별 가격·통화·인원·요금제·취소 정책을 보존한다.
- 직원의 지점 접근 제한은 서버에서 검증한다.
- 체크아웃한 실제 객실은 청소 필요 상태가 된다. 투숙 상태와 청소 상태는 별도로 관리한다.
- AI는 가격·빈 객실을 생성하지 않으며 결제·예약 확정을 실행하지 않는다.
- OTA·도어록·여권 수집·복잡한 회계·매출 최적화는 첫 버전에서 제외한다.
