# 직원 개발 로그인·지점 권한 설계

상태: 구현 대상.

관리자 전용 인증은 고객 예약 관리 토큰과 분리한다. 서버는 개발용 직원 계정의 비밀번호 해시와 세션 토큰 해시만 보관한다. 브라우저에는 무작위 세션 토큰만 남기며, API 요청은 `X-Staff-Session` 헤더로 전달한다.

역할은 `HQ_ADMIN`과 `BRANCH_STAFF`다. 본사 계정은 모든 호텔 지점을 대상으로 한 관리자 API에 접근할 수 있다. 지점 직원은 자신의 `hotel_id`와 일치하는 지점만 조회·변경할 수 있다. 지점 식별자는 요청 값만으로 신뢰하지 않고, 세션에서 확인한 직원 권한과 함께 서버에서 검증한다.

첫 단위는 로그인, 현재 세션 조회, 보호된 지점 접근 검사만 제공한다. 로그아웃은 세션을 폐기한다. 실제 예약·객실 상태 변경 API와 Next.js 로그인 화면은 다음 단위에서 연결한다.

개발 데이터에는 본사·속초·설악산·제주 계정을 만든다. 비밀번호 원문은 저장소에 저장하지 않고, 개발 실행 시 환경 변수로 공급한다. 환경 변수가 없으면 개발 로그인 기능은 비활성화한다.

완료 기준은 다음과 같다.

- 유효한 개발 계정은 세션을 받고 현재 사용자 정보를 조회할 수 있다.
- 지점 직원은 다른 지점 식별자로 보호된 API를 요청해도 거부된다.
- 본사 계정은 모든 지점을 조회할 수 있다.
- 비밀번호와 세션 원문은 DB에 저장하지 않는다.
