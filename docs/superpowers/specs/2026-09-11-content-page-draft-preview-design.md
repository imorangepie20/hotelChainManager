# 일반 콘텐츠 페이지 초안 미리보기 설계

최종 갱신: 2026-09-11

## 목적

본사 관리자가 `CONTENT_PAGE`의 HERO, TEXT, CTA를 저장하거나 발행하기 전에 고객 웹과 유사한 구성으로 확인한다. 미리보기는 현재 편집 폼의 메모리 상태를 사용하므로 서버의 초안과 다를 수 있음을 명확히 알린다.

## 범위와 결정

- 대상은 `CONTENT_PAGE`다. `HOME_PAGE`와 `HOTEL_LANDING`은 각 기존 편집기의 미리보기 범위를 유지한다.
- 미리보기는 페이지 정보, 검색 결과 SEO, HERO, TEXT, CTA의 현재 입력값을 읽는다. 저장 전 변경도 즉시 반영한다.
- 미리보기 열기·닫기는 저장, 발행, 보관, 복원, 미디어 변경 API를 호출하지 않는다.
- HERO 이미지는 고객 웹과 같은 로컬 이미지 또는 업로드 미디어 전달 경로 형식만 표시한다. 허용되지 않거나 빈 경로는 이미지를 요청하지 않고 자리표시자로 대체한다.
- CTA는 시각적으로 표시하되 대화상자 안에서 고객 경로 이동을 일으키지 않는다.
- 페이지가 보관된 경우에도 마지막 초안을 읽기 전용으로 미리 볼 수 있다. 편집 가능 여부와 미리보기 가능 여부는 분리한다.

## 관리자 UX

편집기 상단 작업 영역에 `미리보기`를 둔다. 대화상자 제목은 `일반 페이지 미리보기`이고, `저장하거나 발행하지 않은 현재 편집 내용을 기준으로 표시합니다.`라는 설명을 제공한다. 큰 화면은 폭을 넓혀 고객 콘텐츠의 흐름을 보여 주고, 좁은 화면에서는 세로 스크롤로 이용한다.

HERO는 이미지, 어두운 오버레이, eyebrow, 제목, 설명, CTA를 표시한다. 뒤따르는 TEXT와 CTA는 고객 웹의 정보 위계와 유사하게 차례로 표시한다. 빈 선택 입력은 `제목을 입력해 주세요`, `내용을 입력해 주세요` 같은 비파괴적 자리표시자로 보완한다. `닫기` 버튼과 Escape로 닫을 수 있으며, 닫은 뒤 시작한 `미리보기` 버튼으로 포커스가 돌아간다.

## 구현 경계

- 서버 API, DB schema, page version, audit, media usage는 변경하지 않는다.
- 고객 웹 컴포넌트를 관리자 번들에 직접 의존시키지 않는다. 고객 페이지의 문서 규칙을 따라 관리자 전용 읽기 컴포넌트가 표현한다.
- 이미지 허용 규칙은 고객 `safeMediaDeliveryPath`와 같은 `/images/...`, `/api/website/media/{uuid}/content` 형식을 사용한다. 관리자 origin에서 실제 API 미디어를 표시할 수 있도록 같은 origin 기준 절대 URL만 구성한다.
- 실제 CTA navigation, 미리보기 전용 공개 URL, SEO head 갱신, 다국어 미리보기는 후속 범위다.

## 검증 기준

- Playwright는 일반 콘텐츠 페이지에서 저장하지 않은 HERO와 TEXT 변경이 미리보기 dialog에 표시되는지 확인한다.
- 같은 흐름에서 PUT, POST, publish, archive, restore, media 요청이 없음을 확인한다.
- 닫기 버튼과 Escape 뒤 `미리보기` 시작 버튼으로 포커스가 복귀하는지 확인한다.
- TypeScript 검사를 실행한다. 관리자 전용 변경이므로 서버 재빌드나 실제 사용자 페이지 저장·발행은 수행하지 않는다.
