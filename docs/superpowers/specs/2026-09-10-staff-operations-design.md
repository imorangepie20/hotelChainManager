# 직원 객실 운영 흐름 설계

상태: 구현 대상.

판매 단위인 `room_type`과 실제 배정 단위인 `physical_room`을 분리한다. 예약은 객실 유형별 재고를 확정한 뒤에도 실제 객실 번호를 즉시 가지지 않으며, 지점 직원이 체크인 전에 실제 객실을 배정한다.

직원 흐름은 다음 순서다.

1. 지점 직원은 자신의 지점에서 확정 예약에 실제 객실을 배정한다.
2. 배정된 객실이 모두 청결 상태일 때 체크인한다.
3. 체크아웃하면 예약은 `CHECKED_OUT`, 해당 객실은 `NEEDS_CLEANING`으로 전환한다.
4. 하우스키핑 완료는 객실을 `CLEAN`으로 되돌린다.

객실 배정은 예약의 객실 유형·지점·숙박 날짜와 일치해야 한다. 같은 실제 객실은 겹치는 숙박 기간의 다른 활성 예약에 배정할 수 없다. 본사 계정은 모든 지점, 지점 직원은 소속 지점만 변경할 수 있으며 서버가 이를 검사한다.

첫 단위에는 실제 객실·배정·체크인·체크아웃·청소 완료 API와 통합 테스트를 추가한다. 운영 대시보드 UI 연결, 달력, 노쇼·객실 변경·고객 요청은 다음 단위다.
