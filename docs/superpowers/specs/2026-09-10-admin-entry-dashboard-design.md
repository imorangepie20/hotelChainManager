# 관리자 진입 대시보드 설계

상태: 구현 대상.

관리자 앱은 제공된 `SDTPL_ADM/`의 Next.js 구조와 Card·Button·Sidebar 컴포넌트를 유지하고 4001 포트에서 실행한다. 첫 화면은 본사 또는 지점 컨텍스트를 선택해 그 역할의 업무 우선순위를 보여 주는 정적 운영 대시보드다.

본사 선택에서는 속초·설악산·제주 지점의 준비 상태와 향후 지표 영역을, 지점 선택에서는 오늘 도착·출발·객실 배정·청소 업무의 준비 상태를 보인다. 이 단계에는 API 호출, 예약 변경, 로그인이 없다. 데이터가 준비되지 않았다는 점을 화면에 명확히 표시한다.

다음 구현 단위에서 개발 계정 로그인과 서버 지점 권한 검증을 추가한다. 그 뒤 실제 객실 번호·객실 상태·예약 배정과 체크인·체크아웃·청소 전이를 Spring Boot API로 연결한다. 지점 직원은 자신의 지점만 조회·변경할 수 있어야 한다.

완료 기준은 4001에서 앱이 열리고, 본사·속초·설악산·제주 컨텍스트가 키보드와 마우스로 전환되며, 제공 테마의 공통 컴포넌트가 재사용되는 것이다. 실제 운영 데이터와 인증은 완료 기준에 포함하지 않는다.
