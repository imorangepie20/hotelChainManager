# AI 예약 도우미 구현 계획

1. `services/concierge`에 FastAPI·LangGraph 의존성, 상태 모델, API 클라이언트와 Dockerfile을 만든다.
2. 조건 추출·누락 질문·실재고 검색·후보 비교 노드를 구현하고, API 응답을 기반으로 한 단위 검증을 추가한다.
3. Compose에 AI 서비스와 9000 포트를 추가하고 readiness·한 번의 대화 API를 확인한다.
4. 고객 웹에 대화 패널을 추가한다. 추천 적용은 기존 검색 상태만 바꾸며 예약 생성은 기존 화면에서만 한다.
5. 대상 Python 검증, 고객 빌드, 브라우저 대화→추천 적용→객실 검색을 확인하고 변경 기록에 남긴다.
