# 운영 통계 비교·차트·한영 전환·XLSX 계획 (2026-09-27)

> 상태: 구현·대상 검증 완료. 기준 문서는 `docs/plans/admin-menu-roadmap.md` 4번이다.

## 변경 이유

현재 운영 통계는 선택 기간의 숫자와 CSV만 제공한다. 본사 담당자가 개선·악화를 판단하려면
직전 동일 길이의 기간을 별도로 조회해 비교해야 하고, 차트·영문 화면·실제 Excel 파일도 없다.

## 계약

1. 기존 `GET /api/staff/reports/operations`의 현재 기간 필드와 숫자는 바꾸지 않는다.
2. 응답에 `previousPeriod`를 additive하게 추가한다. 선택 기간이 N일이면 비교 기간은
   `from - N일`부터 `from - 1일`까지의 N일이다.
   `previousPeriod`는 `from`, `to`, `days`, `totals`를 가지며 이전 데이터가 없으면 모든 합계가 0이다.
3. 현재·이전 기간은 모두 예약·변경 요청의 `created_at`을 `Asia/Seoul` 날짜로 변환하고,
   점유율은 `inventory_day.stay_date`를 사용한다. 매출의 취소·노쇼 제외 기준도 유지한다.
4. 증감률은 UI 표현이며 이전 값이 0이면 퍼센트를 만들지 않고 절대 증감만 안내한다.
5. XLSX는 `HQ_ADMIN` 전용 읽기 API가 같은 서비스 집계 결과를 받아 생성한다. DB mutation,
   임시 테이블, 감사 쓰기를 하지 않는다.
   endpoint는 `GET /api/staff/reports/operations/export.xlsx`이고 `from`, `to`, 선택 `hotelId`,
   `locale=ko|en`을 받는다. 기존 조회와 같은 400·401·403·404 검증을 적용한다.
6. XLSX에는 요약과 지점별 행을 숫자 셀로 저장한다. 기간·시간대와 현재/이전 값을 포함하고,
   `locale=ko|en`에 따라 시트명·열 제목을 바꾼다.
   MIME은 OOXML workbook 형식이고 파일명은 `operations-report-{from}-{to}.xlsx`다. 데이터 문자열은
   수식 셀로 만들지 않아 `=`, `+`, `-`, `@`로 시작하는 지점명도 실행되지 않는다.
7. 기존 브라우저 CSV 생성 함수와 열·값은 유지한다.
8. 관리자 화면의 한영 전환은 현재 화면 안에서만 동작하며 API 숫자나 날짜 필터를 바꾸지 않는다.
9. 차트는 기존 Recharts 공통 컴포넌트를 사용하고 제목·설명·키보드 접근 가능한 데이터 표를 함께
   제공한다. 390px에서는 가로 페이지 스크롤 없이 카드 안에서 읽을 수 있어야 한다.
10. 기존 미래 방향 프리셋을 함께 바로잡는다. `Asia/Seoul`의 오늘을 한 번 캡처해 `to=오늘`,
    `from=오늘-(N-1)`로 계산하며 UTC 문자열 변환을 사용하지 않는다.
11. 객실 유형 지점 선택은 하드코딩 UUID가 아니라 조회된 `report.hotels`를 사용한다. 현재 선택이
    사라졌을 때만 첫 지점으로 이동한다.
12. 최대 조회 기간은 inclusive 92일이다. 92일은 허용하고 93일은 400으로 거절한다.
13. 비교 증감은 기존 요약 카드 4종(예약·매출·변경 대기·변경 완료)에 표시한다. 이전 값이 0이고
    현재 값이 양수면 `신규/New`, 둘 다 0이면 0%로 표시한다. 데이터 고유명은 번역하지 않는다.

## 구현 순서

1. 이전 동일 기간 집계와 XLSX 파일 계약을 실패하는 Spring 테스트로 고정한다.
2. 관리자 한영 전환, 비교 문구, 차트 접근성, XLSX 다운로드와 390px 실패 테스트를 추가한다.
3. 서버 응답 모델·집계 재사용 구조·XLSX 생성기와 다운로드 endpoint를 구현한다.
4. 관리자 API 타입·번역 사전·비교 카드·차트·다운로드를 구현한다.
5. 대상 서버 테스트, 관리자 TypeScript·Playwright, XLSX ZIP/XML 및 POI 재로딩 결과를 검증한다.

## 구현 결과

- 운영 통계 응답에 직전 동일 일수의 `previousPeriod` 합계를 추가하고, 기존 현재 기간 필드와
  집계 SQL의 서울 날짜·매출 제외 기준은 유지했다.
- Apache POI 기반 XLSX 생성기와 본사 전용 다운로드 API를 추가했다. 한국어·영어 시트와 숫자
  셀을 만들며, 지점명·지역은 수식으로 평가되지 않는 문자열 셀로 저장한다. 인증 파일 응답은
  `Cache-Control: no-store`로 캐시하지 않는다.
- 관리자 화면에 네 요약 카드의 절대·비율 증감, Recharts 막대 차트와 동일 데이터 표,
  키보드 가능한 한영 전환, XLSX 다운로드를 추가했다.
- 같은 조건 새로고침은 객실 유형 상세도 함께 갱신하며, 변경된 기간을 조회하는 동안에는 이전
  보고서의 CSV/XLSX 내보내기를 비활성화한다.
- 기간 프리셋을 서울 오늘까지의 과거 N일로 고치고, 객실 유형 대상 지점을 API 응답 목록으로
  전환했다. 최대 조회 기간은 inclusive 92일로 통일했다.

## 완료 기준

- 현재 기간의 기존 API·CSV 숫자와 기간·시간대 기준이 유지된다.
- 이전 동일 기간의 경계와 호텔 필터가 서버 테스트로 확인된다.
- XLSX가 유효한 ZIP/OOXML이고 기간·현재/이전 숫자 셀·한영 머리글을 포함한다.
- 화면에서 한국어·영어를 전환해도 재조회나 숫자 변화가 없다.
- 차트에 시각적 막대뿐 아니라 접근 가능한 제목·설명·데이터 표가 있다.
- 관리자 컴포넌트 흐름과 390px 화면에서 다운로드·언어 전환·차트가 검증된다.
- 변경 이유, 검증 결과와 미검증 항목을 한국어 변경 기록에 남긴다.
