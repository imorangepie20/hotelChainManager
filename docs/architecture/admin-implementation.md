# 관리자 구현 순서

기존 사용자 요구와 관리자 참조 분석을 기준으로 제공 테마를 직접 활용한다. 첫 단위는 4001 포트의 관리자 진입 화면이다. 본사는 지점 비교, 지점은 도착·출발·객실·청소 업무를 우선한다. 실제 API 연결 전에는 수치를 생성해 표시하지 않고 준비 상태를 명시한다.

다음 단위는 본사·지점 개발 계정 로그인과 서버 지점 권한 검증이다. 이후 실제 객실 번호와 배정 정보를 추가하고 예약 확인 → 배정 → 체크인 → 체크아웃 → 청소 완료를 연결한다. 체크아웃은 객실을 청소 필요 상태로 바꾸며 청소 전에는 새 투숙객 체크인을 허용하지 않는다.

진입 화면 완료 기준: 제공 Card·Button을 재사용하고 본사·속초·설악산·제주 선택에 맞는 안내를 표시한다. 타입 검사와 실제 4001 HTTP 응답을 확인한다. 데이터 연결·인증 완료로 보고하지 않는다.
