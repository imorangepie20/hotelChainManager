# CMS 콘텐츠 페이지 선택기 표시명 수정

## 문제

관리자 웹사이트 CMS의 `콘텐츠 페이지 만들기` 대화상자에서 콘텐츠 유형은 `BRAND`, 상위 섹션은 UUID처럼 내부 저장값으로 표시됐다. 선택 목록에서는 한글 이름을 보여주지만 Base UI Select에 값과 표시명의 대응 목록을 전달하지 않아, 선택 후 트리거가 원시 값을 렌더링한 것이 원인이었다.

## 변경

- 콘텐츠 유형 Select에 `BRAND → 브랜드` 같은 표시명 목록을 전달했다.
- 상위 섹션 Select에 페이지 트리의 `id → label` 대응 목록을 전달했다.
- 같은 대화상자의 소유 지점과 객실 유형 Select에도 표시명 목록을 전달해 UUID 노출을 예방했다.
- API 생성 요청은 기존과 같이 UUID와 enum을 사용하므로 서버 계약과 저장 데이터는 바꾸지 않았다.
- 기존 CMS 회귀 테스트의 모호한 `미리보기` 버튼 선택자 두 곳을 정확 일치로 고쳤다.

## 검증

- 핵심 페이지 생성 회귀 2건 통과
- `website-content-editor.spec.ts` Chromium 62건 전체 통과
- 관리자 `tsc --noEmit` 통과
- 변경 파일 ESLint 오류 0건, 기존 규칙 경고 2건

## 비변경 범위

- API·DB·콘텐츠 페이지 구조는 변경하지 않았다.
- 선택 목록과 생성 요청의 값은 그대로이며 화면에 표시하는 이름만 수정했다.
