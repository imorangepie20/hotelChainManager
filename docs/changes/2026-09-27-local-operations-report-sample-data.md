# 로컬 운영 통계 샘플 데이터

## 변경 이유

로컬 개발 DB의 최근 14일 예약이 0건이라 운영 통계의 현재/이전 기간 증감, 지점별 차트,
점유율과 변경 요청 상태를 실제 데이터로 확인할 수 없었다. 운영·테스트 DB에는 영향을 주지 않고
로컬 `hotel_chain` 개발 DB에만 재실행 가능한 샘플을 입력했다.

## 입력 내용

- 최신 `R__demo_data.sql`을 로컬 DB에 적용해 누락돼 있던 설악산·제주 객실 유형 6개와 요금제
  6개, 일자 요금·재고를 보완했다. 기존 속초 데이터는 `ON CONFLICT DO NOTHING`으로 유지했다.
- [운영 통계 샘플 SQL](../../scripts/dev/seed-operations-report-sample.sql)을 추가했다.
  `hcm_local_sample=1` psql 변수가 없으면 실행을 중단하며, 고정 UUID와 upsert를 사용해 반복 실행해도
  예약·변경 요청이 중복되지 않는다.
- 서울 오늘 기준 현재 7일과 이전 7일에 세 지점의 확정·취소·노쇼·만료 예약을 분산했다.
  예약은 총 98건이며 지점별 14일 건수는 속초 35건, 설악산 21건, 제주 42건이다.
- 9개 객실 유형의 최근 14일 재고 126행에 점유 수를 설정했다. 현재 7일 점유율은 속초 50.0%,
  설악산 65.0%, 제주 76.9%다.
- 각 지점의 현재/이전 기간에 변경 대기 1건과 완료 1건씩, 총 12건을 입력했다.

## 실행 방법

```powershell
docker compose cp scripts/dev/seed-operations-report-sample.sql db:/tmp/hcm-report-sample.sql
docker compose exec -T db psql -U hotel_app -d hotel_chain -v ON_ERROR_STOP=1 -v hcm_local_sample=1 -f /tmp/hcm-report-sample.sql
```

## 검증 결과

- 스크립트를 두 번 실행한 뒤에도 예약 98건, 변경 요청 12건으로 동일해 중복이 없음을 확인했다.
- 서비스와 같은 `Asia/Seoul` 날짜 및 취소·노쇼 매출 제외 조건으로 직접 집계했다.
  - 현재: 속초 21건/2,433,000원, 설악산 14건/1,462,000원, 제주 28건/4,054,000원
  - 이전: 속초 14건/1,428,000원, 설악산 7건/1,050,000원, 제주 14건/1,628,000원
- 로컬 API readiness와 관리자 페이지는 각각 HTTP 200이다.

## 미검증 항목

- 현재 실행 중인 API 컨테이너는 작업 트리의 최신 코드를 재빌드하지 않았다.
- 관리자 로그인 후 실제 화면 렌더링과 XLSX 다운로드는 이번 데이터 입력 범위에서 다시 수행하지 않았다.
- 운영·배포 DB와 테스트 DB에는 이 샘플을 적용하지 않았다.
