# 예약 임시 확보와 접근 제어

예약·숙박일별 금액·멱등 요청 스키마와 예약 생성·조회 API를 추가했다. 예약 생성 시 객실 유형과 요금제 관계, 수용 인원, 전 숙박일 재고, 최신 총액을 서버에서 다시 검사한다. 재고 행은 날짜순으로 잠근 뒤 한 트랜잭션에서 모두 확보한다.

브라우저가 생성한 32바이트 Base64URL 관리 토큰은 원문을 저장하지 않고 디코딩한 바이트의 SHA-256 해시만 저장한다. 같은 토큰과 멱등 키는 PostgreSQL 트랜잭션 advisory lock으로 직렬화한다. 같은 요청은 기존 예약을 반환하고 내용이 바뀌면 `IDEMPOTENCY_CONFLICT` 409를 반환한다. 다른 토큰과 없는 예약은 모두 404로 처리한다.

TDD에서 구현 전 예약 테스트의 컴파일 실패를 확인했다. 최초 구현 후 PostgreSQL JDBC가 `Instant`를 직접 바인딩하지 못해 실패한 원인을 확인하고 `Timestamp`로 명시 변환했다. 최종적으로 실제 테스트 DB에서 예약 테스트 5개와 전체 API 테스트 11개가 통과했다. 예약 생성 HTTP 호출과 Docker API 이미지 재빌드는 테스트 결제 흐름이 추가된 뒤 함께 검증한다.
