# 관리자 진입 대시보드 변경 기록

## 변경 이유
제공된 `SDTPL_ADM/` 테마를 호텔 체인 운영 관리의 첫 화면으로 전환했다. 실제 예약·객실 운영 API가 연결되기 전에는 임의의 지표를 표시하지 않고 준비 상태만 안내한다.

## 구현 내용
- 기본 대시보드 위젯을 `OperationsOverview`로 교체했다.
- 본사·속초·설악산·제주 컨텍스트 버튼을 추가했다. 선택 상태는 `aria-pressed`와 키보드 포커스로 전달된다.
- 본사는 지점별 데이터 연결 준비 상태를, 지점은 도착·출발·객실 배정·청소 업무 준비 상태를 표시한다.
- 관리자 개발·E2E 포트를 4001로 맞췄고, 패키지 빌드 스크립트는 모두 명시적으로 비실행 처리했다. 이 설정은 빌드 스크립트를 실행하지 않는다.
- 앱 메타데이터, 문서 언어, 사이드바 브랜드를 호텔 체인 관리자에 맞췄다.

## 검증
- `e2e/hotel-operations-overview.spec.ts` 통과: 본사 화면에서 속초 지점으로 전환하고 `aria-pressed` 상태와 지점 업무 카드를 확인했다.
- Next.js 최적화 빌드 성공.
- `http://127.0.0.1:4001/dashboard/default` HTTP 200 확인.

## 미검증·다음 작업
- 실제 브라우저 시각 검증은 Codex 브라우저 인증 토큰을 사용할 수 없어 이 실행에서는 수행하지 못했다.
- 로그인·직원 지점 권한·Spring Boot API·예약 지표·객실 배정과 체크인/체크아웃/청소 상태 변경은 아직 연결하지 않았다.
