# 하네스·스킬·플러그인 현황 문서화

## 변경 이유와 내용

사용자가 프로젝트에 설치되거나 사용되는 하네스와 추가 스킬·플러그인의 문서화를 요청했다. [계획](../plans/2026-09-20-harness-skill-plugin-inventory.md)에 범위와 완료 기준을 기록하고 [현황 문서](../harness/installed-harness-skills-plugins.md)를 작성했다. 현재 개발 상태에 안내 링크를 추가했다.

프로젝트 규칙과 이식 원문, 로컬 Impeccable, 사용자 공통 스킬 58개, Codex 사용자·시스템 스킬, 명시 활성 플러그인 15개 및 추가 캐시·세션 제공 항목을 구분했다. 버전 출처와 실제 프로젝트 사용 기록을 표시하고, 원문의 옛 버전·경로·테마 수정 규칙 차이를 정리했다. 기존 이식 원문과 제품 코드·설정은 변경하지 않았다.

## 검증

- 저장소 규칙·문서, 스킬 SKILL.md·VERSION, 플러그인 plugin.json, 사용자 설정의 플러그인 ID·활성화 값, 현재 세션 제공 목록을 대조했다.
- 문서의 사용자 공통 스킬 58개를 실제 디렉터리 목록과 대조하고, 명시 활성 플러그인 15개를 설정과 대조했다.
- 새 문서 3개의 상대 링크 대상과 공백 오류를 검사했다. 현재 개발 상태에 추가한 안내 링크도 확인했다.
- 문서만 변경했으므로 제품 빌드·테스트·DB/API·UI 회귀는 실행하지 않았다.

## 미검증 항목과 다음 작업

스킬·플러그인의 실제 실행, Impeccable 훅 작동, 외부 계정 연결, 온라인 최신 버전과 새 PC 재현은 확인하지 않았다. 필요한 도구를 실제로 사용할 때 최소 실행 결과를 별도 기록한다. 파일 존재를 기능 완료로 보고하지 않는다.
