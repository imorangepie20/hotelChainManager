# 관리자 호텔·객실 지점 선택 명확화

## 변경 이유

호텔·객실 화면의 지점 선택은 글자 굵기만 달라 현재 선택을 알아보기 어려웠고, 재고·가격 화면은 서버 지점 목록이 아닌 하드코딩 목록을 사용했다. 지점 전환 도중 이전 지점 결과나 늦은 상세 조회 응답이 현재 지점 화면에 섞일 가능성도 있었다.

## 변경 내용

- 호텔·객실 지점 표에 선택 행 배경, `aria-pressed`, `선택됨` 배지를 추가했다.
- 호텔·객실과 재고·가격 결과 제목에 현재 선택한 지점명을 표시했다.
- 재고·가격 지점 선택기를 `getStaffHotels` 서버 응답 기반으로 변경했다.
- 지점 전환을 시작하면 이전 결과를 즉시 숨기고, 현재 지점 ID와 일치하는 응답만 표시한다.
- 객실유형·요금·재고 변경 요청 중에는 지점 선택을 잠가 이전 지점 작업 완료 콜백이 새 지점 조회를 무효화하지 못하게 했다.
- 대화상자를 닫거나 지점을 바꾸면 진행 중인 객실 기본값·일자별 요금 조회를 generation으로 무효화한다. 이전 지점의 늦은 응답은 새 지점 입력값과 로딩 상태를 변경하지 않는다.
- 마우스뿐 아니라 키보드로 지점을 바꾸는 경로와 390px 모바일 화면을 회귀 검사했다.
