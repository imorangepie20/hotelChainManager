# 모의 결제와 확보 만료

개발·테스트 설정에서만 노출되는 모의 결제 API와 결제 시도 테이블을 추가했다. 성공은 각 숙박일의 확보 수량을 확정 수량으로 이동하고, 실패는 결제 대기 상태와 확보 재고를 유지한다. 결제 멱등 키를 예약별로 저장해 성공 재요청이 재고를 다시 이동하지 않게 했다.

만료 정각부터 결제를 거절하고 예약을 `EXPIRED`로 바꾸며 확보 재고를 반환한다. 이 경로는 만료 예외가 발생해도 트랜잭션이 커밋되도록 분리했다. 배치 만료는 최대 100건을 조회하고 예약별 트랜잭션으로 처리한다. 모든 경로는 예약 행을 먼저 잠근 뒤 숙박일 재고를 날짜순으로 잠근다.

구현 전 결제 테스트의 컴파일 실패를 확인했다. 실제 PostgreSQL에서 성공·실패·중복 성공·만료 정각·결제와 만료 경합의 5개 통합 테스트가 통과했다. 전체 테스트 반복은 취소 구현 뒤 한 번만 수행한다.
