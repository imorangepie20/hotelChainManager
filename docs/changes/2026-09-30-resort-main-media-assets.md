# 리조트 메인 미디어 자산 15개 등록

날짜: 2026-09-30
상태: **자산 등록·5장 계약·Motion 구현 완료, 운영 랜딩 연결·공개 반영 미수행**

## 범위

속초·설악산·제주 지점의 메인 화면에 사용할 이미지를 지점별 5개, 총 15개 준비해 운영 관리자 미디어 자산으로 등록했다. 임의의 웹 검색 이미지는 사용하지 않았고, 기존 지점 대표 이미지와 특정 실제 호텔 브랜드를 복제하지 않은 생성 이미지를 조합했다.

로컬 최종 파일은 `artifacts/resort-assets/final/`에 작업 산출물로 두었다. 15개 JPEG는 모두 1600×900이며 `assets.json`에 지점, 파일명, 자산명, 한국어 대체 텍스트를 기록했다. 관리자 등록 과정에서 자산명을 일관된 “지점 + 장면” 형식으로 정규화했으며, 재조회한 실제 관리자 값으로 `assets.json`도 동기화했다. 이 디렉터리는 `.gitignore`의 `artifacts/` 규칙으로 Git 배포 대상에서 제외하며 제품 배포 파일로 간주하지 않는다.

## 검증

- 로컬 최종 JPEG: 15개, Pillow 형식 검증 성공.
- 관리자 미디어 목록: 활성 자산 15개 재조회 성공.
- 지점별 수량: 속초 5개, 설악산 5개, 제주 5개.
- 메타데이터: 15개 모두 자산명과 한국어 기본 대체 텍스트 존재.
- 관리자 `저장소 점검`: `로컬 · 정상`, `DB 참조와 저장 파일이 모두 일치합니다.` 확인.
- 자산을 검토할 때 하단 `선택`을 누르지 않고 `취소`로 닫아 기존 랜딩 초안과 발행본을 변경하지 않았다.

- 따라서 이 기록은 “Google이 출력 소유권을 주장하지 않는다”는 조건을 확인한 것이며, 배타적 저작권·제3자 권리 비침해·모든 계정 유형의 상업적 사용을 Google이 보증한다는 뜻이 아니다. 실제 상업 캠페인 전에는 사용 계정의 조직·학교·사업자 약관과 관할 법률을 다시 확인한다.
