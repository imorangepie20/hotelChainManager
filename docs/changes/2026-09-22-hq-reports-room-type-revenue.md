# 본사 운영 통계 - 객실 유형별 매출·CSV 내보내기 (2026-09-22)

> 상태: 작업 트리에만 있고 커밋하지 않은 상태.

## 변경 이유

`admin-menu-roadmap.md` 4번 `운영 통계·리포트`의 남은 항목 중 "객실 유형별·요금제별 상세 매출"과 "CSV·Excel 내보내기"를 구현했다. 지점별 합계만 있어서 **어느 객실 유형이 매출을 만드는지 알 수 없었고**, 보고서를 공유하려면 화면을 캡처해야 했다.

## 서버 변경

- `GET /api/staff/reports/operations/room-types?hotelId=...`가 한 지점의 객실 유형별 예약·취소·노쇼·매출·매출 비중을 반환한다. **SELECT만 사용**하고 가격·재고·예약 상태를 변경하지 않는다.
- 매출 집계는 지점별 보고서와 **같은 기준**을 쓴다. 취소·노쇼가 아닌 예약의 금액만 합산해서 실제 숙박으로 이어진 예약만 인정한다.
- **`hotelId`는 필수**다. 객실 유형은 지점 안에서만 의미가 있고, 빠지면 400이다. 없는 지점은 404, 역순 기간은 400, 93일 초과는 400이다. 기간을 생략하면 최근 7일(지점 현지 시간대 기준)이다.
- 매출 비중은 지점 전체 매출에서 해당 유형이 차지하는 몫이다. **지점 매출이 0원이면 비중을 계산하지 않고 0**으로 둔다. 0으로 나누는 것을 막기 위해서다.
- `HQ_ADMIN`만 호출 가능하고 지점 직원은 403, 잘못된 세션은 401이다. 마이그레이션은 필요 없다. 기존 `reservation`·`room_type` 테이블에서 읽기만 한다.

## 관리자 UI 변경

- `운영 통계` (`/dashboard/reports`)에 `객실 유형별 대상 지점` 선택기와 객실 유형별 매출 표를 추가했다. 지점을 바꾸거나 기간 프리셋을 누르면 같은 세대에서 다시 불러온다.
- 매출 비중은 `Badge`로 표시하고 50% 이상이면 강조한다. 비중 아래에 절대 금액을 함께 보여준다.
- `CSV 내보내기` 버튼을 추가했다. **브라우저에서 파일로 내려준다. 서버를 거치지 않는다.** 매개변수 조작이나 헤더 주입이 없다.
- CSV에는 UTF-8 BOM을 붙였다. BOM이 없으면 엑셀이 한글을 깨져서 보이기 때문이다.
- 빈 기간이면 지점별 표의 안내와 별도로 객실 유형별 안내(`room-type-empty`)를 보여준다.

## 검증 결과

- API `mvnw -Dtest=OperationsReportIntegrationTest` **18건**(기존 10 + 신규 8)이 종료 코드 0이다. 새 검증은 객실 유형별 매출 200·6건·매출 400,000·비중 1.0·기본 7일·빈 기간 0건 0원·`hotelId` 누락 400·없는 지점 404·역순 400·지점 직원 403·세션 없음 401이다.
- 관리자 `tsc --noEmit`이 종료 코드 0이고, `eslint`는 경고만 낸다(`react-hooks/set-state-in-effect`, 기존 컴포넌트와 같은 패턴).
- Playwright `operations-report` **8건**(기존 6 + 신규 2)이 종료 코드 0이다. 새 검증은 지점 선택기가 객실 유형별 요청을 따라가는지와 CSV 다운로드의 내용이 헤더·두 지점 행을 모두 포함하는지다.

## 발견·수정한 결함

1. Playwright 라우트 글로브 `**/api/staff/reports/operations*`가 새 경로 `/operations/room-types`까지 잡았다. 그래서 객실 유형별 요청이 지점별 보고서 응답을 받아 매출 비중이 깨졌을 것이다. 더 좁은 `/operations?*` 패턴으로 좁히고, `room-types` 경로를 먼저 등록해 Playwright의 라스트 매칭 규칙에서 이기게 했다.
2. `seedStaffScript` 함수의 여는 괄호가 다음 줄과 병합돼 있었다. 컴파일은 되지만 diff가 불분명해져 분리했다.

## 미검증 항목

- 라이브 DB·compose `api` 재빌드·브라우저 확인은 실행하지 않았다. 라이브 데이터로 객실 유형별 매출이 올바르게 내려오는지, CSV가 엑셀에서 한글이 깨지지 않는지는 사용자가 확인한다.
- **차트 시각화·이전 기간 대비 증감·영문 전환·Excel(xlsx) 내보내기는 이번 범위가 아니다.** CSV는 텍스트 편집기·엑셀 모두 열 수 있지만 `.xlsx` 이진 형식은 아니다.
- 요금제별 상세 매출도 빠졌다. 객실 유형별 매출이 의미가 있으려면 먼저 데이터가 쌓여야 하고, 요금제는 같은 유형 안에서 여러 개일 수 있어 집계 단위를 따로 정해야 한다.
- CSV는 본사 세션이 있는 브라우저에서만 내려간다. 서버에 내보내기 엔드포인트가 없으므로 권한 검증은 페이지 진입 시 403/401에 의존한다.
