# 프로젝트 작업 기반과 예약 설계

사용자가 제공한 하네스와 관리자 테마를 호텔 프로젝트에 적용하기 위해 루트 AGENTS.md, 원칙·접근 순서·개요·현재 상태·의사결정 및 예약 설계를 작성했다.

기존 harness와 SDTPL_ADM 파일은 변경하지 않았다. 제품 코드 변경·DB 연결·실행 테스트는 아직 없다. 문서 링크와 생성 파일을 확인하며, 제품 기능 완료를 의미하지 않는다.

## 개발 포트 확정

사용자 요청에 따라 고객 웹 `4000`, 관리자 `4001`, API `4080`, AI `9000`을 의사결정과 현재 개발 상태 문서에 반영했다. 실행 설정은 아직 구성 전이며 이번 변경은 문서에만 적용한다.

## 관리자 디자인 참조 추가

Archify 후속 분석: 참조의 주요 메뉴를 읽기 전용으로 확인하고 관리자 디자인 적용 표 및 서비스 구조도를 생성했다. 구조도 deliver 9/9, 오류·경고 0, 네 데스크톱 크기 visual-check 통과. 상세 증거와 해시는 docs/architecture/admin-reference-analysis.md에 기록했다.

사용자가 지정한 `http://localhost:2455/dashboard`를 SDTPL_ADM과 함께 관리자 디자인 참고 대상으로 기록했다. 브라우저에서 Codex LB 로그인 화면을 확인했으며, 인증이 필요해 대시보드 내부 디자인은 미확인 상태다.

후속 확인: 사용자가 열어둔 Chrome의 로그인된 대시보드에서 화면 구조와 카드·배경·차트 스타일을 확인했다. 의사결정과 현재 상태의 미확인 표기를 갱신했다. 참조 화면의 계정 정보나 업무 데이터는 문서에 복사하지 않았다. UI 구현·반응형 검증은 아직 수행하지 않았다.
