# 관리자 내비게이션 정리

## 변경 이유

제공된 관리자 템플릿의 쇼핑·암호화폐·샘플 앱 메뉴가 실제 호텔 운영 기능처럼 노출되고 있었다. 현재 구현되어 동작하는 호텔 운영 화면만 메뉴에 표시하고, 본사와 지점 직원의 권한 차이를 내비게이션에도 반영했다.

## 구현

- 공통 운영 메뉴를 `운영 대시보드`, `오늘의 운영`으로 정리했다.
- 본사 관리자에게만 `웹사이트 CMS` 메뉴를 표시한다.
- 지점 직원에게는 CMS 메뉴와 검색 결과를 노출하지 않는다. CMS의 최종 권한 검증은 기존대로 Spring API가 수행한다.
- 사이드바 브랜드를 `STAY HANEUL`로, 검색 문구를 한국어로 변경했다.
- 화면이 아직 없는 예약 관리·요금·재고·직원 설정 메뉴는 죽은 링크로 추가하지 않았다.
- 기존 템플릿의 전체 메뉴 정의는 `SDTPL_ADM/src/lib/template-nav.ts`에 별도 보관했다. 운영 메뉴에는 연결하지 않으며, 이후 실제 기능을 구현할 때 기존 페이지·컴포넌트와 함께 항목별로 재사용한다.

## 검증

- Playwright `admin-navigation.spec.ts` 2건 통과: 본사 메뉴, 지점 직원의 CMS 비노출과 검색 결과 제한.
- 관리자 TypeScript `tsc --noEmit` 통과.
- 실제 관리자 개발 화면에서 데스크톱 메뉴와 390×844 모바일 사이드바 열기를 확인했다.

## 다음 작업
