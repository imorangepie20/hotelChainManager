# 본사 감사 이력 통합 조회

> 상태: 작업 트리에만 있고 커밋하지 않은 상태. 최종 갱신: 2026-09-20.
> 구현 계획: [본사 감사 이력 통합 조회 첫 단계](../superpowers/plans/2026-09-20-hq-audit.md)

## 변경 요약

- `admin-menu-roadmap.md` 7번 `감사·이력 조회`의 첫 단계를 구현했다. V29~V37 감사 표와 `reservation_change_event`는 데이터가 쌓이고 있었으나 본사가 읽는 API와 화면이 없었다.
- `GET /api/staff/audit`가 8종 감사 이력을 `UNION ALL`로 묶어 발생 시각 내림차순으로 반환한다. SELECT만 사용하고 상태를 변경하지 않는다.
- 감사 유형은 `GUEST_UPDATE`·`PARTY_UPDATE`·`ROOM_REASSIGNMENT`·`STAY_CHANGE`·`CANCELLATION`·`ROOM_OPERATIONAL_TRANSITION`·`CHECKED_IN_ROOM_MOVE`·`CHANGE_REQUEST_EVENT` 8종이다.
- `reservationId`·`hotelId`·`from`·`to`·`limit`·`offset` 필터를 지원한다. `limit`은 1~200, `offset`은 0 이상, 기간 끝날짜는 시작 날짜 이후, 위반은 400이고 없는 지점은 404다.
- `HQ_ADMIN`만 호출 가능하고 지점 직원은 403, 잘못된 세션은 401이다.
- 직원 취소만 감사에 노출하고 고객 취소(`actor_type = 'CUSTOMER'`)는 제외한다. `reservation_change_event`는 `actor_staff_id`가 있는 전환만 노출한다.
- 각 이력에는 처리 직원 이메일·이름·역할, 지점 이름, 예약 id·고객 이름(있을 때), 객실 번호(있을 때), 이전·이후 요약이 포함된다. 원본 `payload` JSON은 노출하지 않는다.
- 관리자 `/dashboard/audit`에 유형별 표와 더 보기 페이지 이동을 추가했다. `nav.ts`의 `본사 관리` 그룹은 `HQ_ADMIN`에만 노출되고, 다른 역할은 본사 전용 안내를 본다.

## 서비스별 변경

### services/api

- `audit/AuditQueryService`(신규): 8종 감사 표를 `UNION ALL`로 묶어 최신순으로 읽는다. 모든 쿼리가 SELECT다.
- `audit/AuditController`(신규): `GET /api/staff/audit`. `requireHeadquarters`로 본사만 허용한다.
- `audit/AuditQueryFilters`(신규)·`audit/AuditEventView`(신규)·`audit/AuditEventsView`(신규).
- 기존 감사 표에 컬럼을 추가하거나 제약을 변경하지 않았다. additive 마이그레이션도 없다.

### SDTPL_ADM

- `src/lib/staff-api.ts`: `getAuditEvents`·`AuditEvent`·`AuditEvents`·`AuditEventType`·`auditEventLabels`를 추가했다. 403·기타 실패 안내를 나눴다.
- `src/components/hotel-admin/audit-events.tsx`(신규): 유형별 표와 더 보기 페이지 이동. `HQ_ADMIN`만 노출.
- `src/app/(dashboard)/dashboard/audit/page.tsx`(신규).
- `src/lib/nav.ts`: `본사 관리` 그룹에 `감사 이력`(`/dashboard/audit`, `History` 아이콘)을 추가했다.
- `e2e/audit.spec.ts`(신규) 7종: 메뉴 노출 권한, 이력 표시, 유형별 한국어 라벨, 다음 페이지 이동, 지점 직원 안내, 장애 안내, 빈 범위 안내.

- Vite production build, 고객 웹 Playwright 회귀는 실행하지 않았다. 변경 범위가 본사 읽기 전용 조회에 국한되므로 사용자가 요청할 때까지 반복하지 않는다.

- 개인정보 마스킹 옵션, CSV·Excel 내보내기, 고객 요청 이력, 지점별 정책과 영문 전환은 범위 밖이다.
