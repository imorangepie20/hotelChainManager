# 고객 예약 화면 연결

고객 웹을 4000 포트에서 실행하고 Spring Boot 4080 API로 검색·확보·테스트 결제·조회·취소를 연결했다. 기본 지점은 재고가 준비된 속초다. 검색 조건 변경 시 이전 결과를 제거하고, 새로고침하면 세션에 저장한 마지막 예약을 조회한다. 생성 요청 전 관리 토큰·멱등 키·본문을 세션에 저장해 응답 유실 시 같은 요청으로 재시도한다.

검증: 고객 앱 TypeScript·Vite 빌드 성공. 실제 브라우저에서 속초 2026-09-17~19 스탠다드 객실 검색, 확보, 결제 실패 안내, 결제 재시도 성공, 새로고침 후 확정 예약 복구, 취소 완료를 확인했다. 첫 Tab 키가 브랜드 링크에 도달하고 포커스 표시가 보이는 것도 확인했다. 실제 결제나 이메일 발송은 없다. 이전 백엔드 검증은 DB·검색·예약·결제/만료·취소 총 20개 테스트 통과다.

남은 작업: 모바일 390×844 실제 해상도 검증, 자동 E2E 파일, 만료 상태의 실제 시간 경과 UI 검증, 아동·다객실 검색, 다국어, 관리자와 AI 연결. 응답이 유실된 생성 요청이 있을 때 별도의 복구 화면을 제공하는 것도 후속 보완이다.

호텔 이미지는 built-in imagegen으로 생성해 `apps/web/public/images/sokcho-coast-hero.png`에 저장했다. 프롬프트 요지: 가상 속초 해안 호텔의 여명 건축 사진, 오른쪽 호텔과 왼쪽 바다 여백, 네이비·청록·아이보리, 텍스트·로고 없음.
