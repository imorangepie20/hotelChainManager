# 속초 지점 실제 영문 번역·발행

## 요청과 실행 범위

사용자가 영어 번역과 영문 발행을 명시적으로 요청했다. 현재 관리자에서 선택된 속초 지점 영어 초안(`/en/stays/sokcho`, 초안 v1)을 대상으로 한다고 알린 뒤 실행했다. 검토·승인 기능 구현은 보류했으며 코드·권한·스키마는 변경하지 않았다.

실행 계획과 완료 기준은 관리자 영어 초안의 소개·경험·오퍼·메뉴·이미지 alt·SEO를 번역하고, 기존 이미지·예약/투숙 기간·체크인/체크아웃 시각을 유지한 채 저장·발행한 다음 고객 공개 화면에서 확인하는 것으로 정했다.

## 실제 변경

- 메뉴 이름을 `Sokcho Ocean Hotel`로 번역했다.
- 히어로 제목·설명, 대표 이미지 alt, 가상 주소·도착 안내, 세 경험의 제목·설명, 두 오퍼의 제목·상세, SEO 제목·설명을 영어로 입력했다.
- 가상 호텔과 가상 주소라는 의미를 이미지 alt·주소·SEO에 유지했다.
- 기존 이미지, 메뉴 순서/노출, 영어 상단 문구와 분류, 예약·투숙 기간, 체크인/체크아웃 시각은 변경하지 않았다.
- 관리자 브라우저에서 영어 초안 저장 성공(v2), 영어 발행 성공(v1)을 확인했다. 발행 이력의 표시 시각은 2026-09-12 20:44:58이다.
- 한국어 페이지에는 저장·발행 요청을 하지 않았다. 다른 지점·홈·브랜드 페이지는 이번 요청 범위에 포함하지 않았다.

## 검증과 미검증

- 실제 고객 `http://localhost:4000/en/stays/sokcho`에서 SEO 제목, 영어 메뉴·히어로·이미지 alt·경험·오퍼·도착 안내, 보존된 기간·시각을 확인했다. 고객 영문 탭을 열린 상태로 유지했다.
- 코드 변경이 없는 실제 콘텐츠 작업이므로 빌드·전체 테스트는 재실행하지 않았다. DB 전체 체크섬·모바일·예약 흐름 재검증은 수행하지 않았다.
- 예약 링크는 기존 구현대로 한국어 예약 화면으로 연결된다. 예약/결제/AI 전체 영어화 및 검토·승인 기능은 아직 후속 작업이다.

이 기록은 사용자 허가로 수행한 실제 콘텐츠 변경이다. 이전 다국어 구현 기록의 '실제 사용자 CMS mutation 없음'은 그 구현·검증 시점의 기록이며, 이번 발행 이후에도 변경이 없었다는 뜻이 아니다.
