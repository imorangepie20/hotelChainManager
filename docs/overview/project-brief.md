# 프로젝트 개요





React·Spring Boot 기반 호텔 체인 예약·운영 플랫폼 및 AI 예약 컨시어지.





국내 지점은 속초·설악산·제주도 3곳이다. 속초와 설악산은 별도 지점으로 구분한다. 각 지점은 객실 유형 3~4개로 구성하며, 현재 데모에는 STAY HANEUL 브랜드명과 가상 주소를 사용한다. 이는 실제 호텔 정보가 아니다.





고객에게 브랜드·지점·객실 소개, 날짜·인원·지역 검색, 객실·요금제 비교, 예약·테스트 결제·조회·취소를 제공한다. 한국어·영어와 모바일 대응을 목표로 하며, 현재 구현·검증 범위는 [현재 개발 상태](current-development-context.md)를 따른다.





지점 직원은 예약 달력, 당일 도착·출발, 객실 배정·변경, 체크인·체크아웃·노쇼, 고객 요청, 청소·점검을 관리한다. 본사는 지점·객실 유형·요금·판매 중지·직원 권한·공통 정책과 예외·변경 이력·매출·점유율·취소율을 관리한다.





기술: React + TypeScript, Java + Spring Boot, PostgreSQL, Python + FastAPI + LangGraph, LLM·임베딩, Docker Compose. 관리자 UI는 제공된 SDTPL_ADM의 Next.js·React 구조를 활용한다.





AI는 조건 추출 → 누락 정보 질문 → 실제 객실 조회 → 후보 비교 → 고객 선택 → 예약 화면 연결을 수행한다. 현재 예약 바 조건을 대화에 전달하고, 추천 적용 시 Spring availability를 다시 조회한 결과만 예약 카드에 사용한다. 정책 검색·출처 표시는 후속 RAG 단계이며, 실제 예약 가격은 계속 API를 사용한다.




본사 CMS는 지점 랜딩을 시작으로 공통 콘텐츠·페이지·오퍼·미디어·다국어·SEO·발행 이력까지 관리하도록 확장한다. 현재는 지점·홈·일반 페이지의 초안/발행, 구조화 폼, 안전한 이미지 카탈로그·업로드·사용 위치, 자산 메타데이터와 참조 보호 보관·복원, 일반 페이지의 공개 중단·초안 복원, 이전 발행본 콘텐츠의 안전한 초안 복원과 두 발행본의 읽기 전용 비교, 저장 전 일반 페이지 초안 미리보기, 보관된 일반 페이지의 영구 삭제까지 연결했다. 세부 운영 기능과 API는 [CMS 기능 명세](../architecture/cms-functional-specification.md), 제품 전체 경계는 [전체 구현 설계서](../architecture/full-site-implementation-design.md)를 따른다.
