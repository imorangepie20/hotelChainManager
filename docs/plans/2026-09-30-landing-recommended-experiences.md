# 지점 랜딩 추천 즐길 거리 구현 계획

작성일: 2026-09-30
상태: Important 리뷰 수정·최종 대상 검증·main 푸시·Zorin 배포 완료, 운영 브라우저 확인은 사용자 수행

## 결정

- 기존 자유 입력 `experiences` 카드는 새 편집 대상에서 제외한다.
- 지점 랜딩 관리자는 같은 지점의 발행된 `DINING`, `FACILITY`, `EXPERIENCE` 상세 페이지를 최대 3개 선택하고 순서만 관리한다.
- 고객 카드의 유형·제목·요약·대표 이미지·URL은 선택한 상세 페이지 발행본에서 서버가 생성한다.
- 랜딩 발행 시 카드 값을 불변 snapshot으로 저장한다. 이후 상세 페이지가 바뀌어도 랜딩을 다시 발행하기 전까지 고객 화면은 바뀌지 않는다.
- 기존 발행본의 `experiences` 배열은 호환 표시한다. 새 추천 snapshot이 있으면 이를 우선한다.

## 구현 순서

1. 랜딩 초안 관계 저장과 같은 지점·허용 유형·중복·최대 3개·연속 순서 검증을 추가한다.
2. 발행 시 상세 페이지 발행본에서 추천 카드 snapshot을 만들고 공개 응답에 보존한다.
3. 한국어·영어 관리자에서 자유 입력 폼을 발행 상세 페이지 선택기와 순서 관리 UI로 교체한다.
4. 고객 한국어·영어 랜딩에서 추천 카드를 안전한 내부 상세 경로 링크로 렌더링한다.
5. 기존 발행본 호환, 키보드·390px, 타입·빌드·대상 회귀를 검증한다.

## 완료 기준

- 선택하지 않은 상세 페이지는 랜딩에 나타나지 않는다.
- 최대 3개가 관리자 지정 순서대로 나타난다.
- 다른 지점, 비허용 유형, 미발행 대상, 중복 대상, 잘못된 순서는 서버가 거부한다.
- 상세 페이지 재발행만으로 기존 랜딩 카드가 암묵적으로 바뀌지 않는다.
- 한국어·영어 초안과 발행본이 독립적으로 동작한다.
- 고객 카드는 제목·요약·이미지와 실제 상세 페이지 링크를 제공한다.
- 기존 `experiences` 기반 발행본은 계속 표시된다.
- 서버 통합 테스트, 관리자 Playwright·TypeScript, 고객 계약·Playwright·production build가 통과한다.

## 구현 결과

- API는 랜딩 관계 검증과 한국어·영어별 발행 snapshot을 구현했다. 최종 대상 통합 테스트 58건이 통과했다.
- 관리자는 한국어·영어 자유 입력 경험 폼을 상세 페이지 선택·순서 UI로 교체했다. TypeScript와 CMS Playwright 68건이 통과했고 390px 키보드 조작·양 언어 stale 제거·카탈로그 경합 회귀도 포함했다.
- 고객 웹은 추천 snapshot을 기존 카드보다 우선하고 안전한 내부 상세 링크와 이미지를 렌더링한다. parser 계약, production build, 대상 Playwright 11건이 통과했다.
- 랜딩 snapshot 이미지 usage 보호, 언어별 발행 카탈로그, stale 추천 제거의 Important 3건을 수정했다. 변경 파일 ESLint는 오류 0·경고 6건으로 통과했다.
- 구현·검증 상세와 운영 미검증 범위는 [변경 기록](../changes/2026-09-30-landing-recommended-experiences.md)을 따른다.

## 커밋·배포 완료 기준

- 관련 소스·테스트·문서를 main에 커밋하고 origin/main SHA 일치를 확인한다.
- clean HEAD archive만 Zorin 서버로 전송해 기존 프로젝트 서비스를 재빌드한다. 비밀값과 다른 프로젝트는 변경하지 않는다.
- 서버 소스와 커밋 archive를 대조하고 서비스 health·공개 고객/API/관리자 응답을 확인한다.
- 배포 결과를 변경 기록과 현재 개발 상태에 반영해 추가 문서 커밋·푸시한다.
- CMS 추천 관계 저장·랜딩 재발행·실제 브라우저 클릭은 사용자가 실행한다. 배포 자체를 운영 콘텐츠 발행 완료로 기록하지 않는다.

## 배포 결과

- 기능 커밋 `2e4d2cc`의 origin/main 일치와 GitHub 고객 웹 검사 success를 확인했다.
- Zorin 서버의 변경 파일 23개 archive SHA-256 일치, 실제 이미지 재빌드·서비스 health·내부/터널 배포 검증을 통과했다. 결과 문서는 추가 커밋·푸시한다.
- 운영 한국어 resolve 3개는 200·추천 0개로 기존 카드가 유지된다. 영어 resolve 3개는 404이며 별도 운영 발행 확인이 필요하다.
- 이번 요청의 소스 배포는 완료됐지만 실제 CMS 추천 저장·발행·고객 카드 클릭은 수행하지 않았다.
