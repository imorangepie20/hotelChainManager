# 하네스·스킬·플러그인 현황 문서화 계획

- 요청: 이 프로젝트에 설치되거나 사용되는 하네스와 추가 스킬·플러그인을 한국어로 정리한다.
- 설계: 저장소 규칙, 이식 원문, 프로젝트 설치, 사용자 전역 설치, 현재 세션 노출, 실제 사용 근거를 구분한다. 캐시 존재를 실행 성공으로 해석하지 않는다.
- 조사: AGENTS.md → 프로젝트 원칙·현황·개요 → 하네스 원문·관련 설계 → 초기 변경 기록 → 로컬 스킬·훅 및 사용자 플러그인 설정의 이름·활성화 값 순서로 확인한다.
- 산출물: `docs/harness/installed-harness-skills-plugins.md` 및 이번 변경 기록. 현재 개발 상태에 안내 링크를 추가한다.
- 범위: 문서만 변경한다. 스킬 설치·갱신, 훅 실행·수정, 계정 연결, 제품 코드 변경은 포함하지 않는다.
- 완료 기준: 현재 목록과 버전 출처, 프로젝트 사용 근거, 원문과의 차이, 미검증 항목을 기록하고 새 문서의 내부 링크·목록 수·diff 공백을 검증한다.
- 검증: 파일·메타데이터·설정 대조 및 Markdown 링크 검사. 제품 코드 변경이 없으므로 DB/API·UI·전체 테스트는 실행하지 않는다.

## 후속 요청: 다른 프로젝트용 단일 문서

- 목표: 다른 파일을 함께 전달하지 않아도 이해하고 적용할 수 있는 한국어 Markdown 문서 1개를 작성한다.
- 구성: 교체 항목, 적용 순서, AGENTS.md·현황·계획·변경 기록 템플릿, 스킬·플러그인 전체 참고 목록, 설치 출처와 확인 수준, Impeccable 이식 주의점, 완료 기준, 새 프로젝트에 전달할 실행 요청문.
- 경계: 호텔 업무·개인 절대 경로·외부 문서 상대 링크를 제거한다. 현재 환경의 버전은 참고 스냅샷이며 새 환경 설치·작동 보장으로 표현하지 않는다.
- 완료 기준: 단일 파일에 필요한 템플릿과 목록이 포함되고, 스킬 58개·명시 활성 플러그인 15개가 원본과 일치하며, 다른 저장소 파일에 의존하는 링크가 없는지 확인한다.

## 후속 보완: 문서만으로 실행 가능한 적용

- 외부 스킬 없이 수행할 기본 절차와 수신 에이전트 실행 지침을 문서에 내장했다.
- 필수 문서 7개의 본문을 포함한 PowerShell 생성 스크립트를 추가했다. 기존 파일은 보존하고 프로젝트 조사·병합을 후속 단계로 명시한다.
- 검증 결과: 임시 디렉터리에서 7개 생성, 재실행 해시 불변, 기존 AGENTS.md 보존 및 6개 추가 생성 통과. 구문·Markdown·외부 파일 경로 의존 부재 확인.
- 미검증: 실제 다른 프로젝트의 도메인 적용과 다른 OS 실행, 외부 플러그인 설치·훅 실행.
